# v2.5.0｜任务编辑、随机批次基础管理与界面优化

本版本增加 WebUI 任务编辑和重要星标操作，开放随机任务的基础信息编辑，统一编辑界面与看板风格，并改善真实用户私聊中的确认体验。

## 修复与改进

- **普通任务直接编辑**：修改内容、分类、开始时间、重复规则、间隔和高级自动动作。按服务器时间填写，保存更新后续调度；已过期的一次性任务须先设置未来时间。
- **随机任务基础编辑**：修改内容、分类和动作，默认仅本条；可选择同批次未到期的任务，包括暂停但未到期项，并显示总条数。仅剩 1 条时隐藏范围选择。保留已抽取时间、任务身份与暂停状态，历史投递不改写。原生 `edit_reminder` 工具同步支持 `edit_batch`。
- **重要星标一键切换**：任务卡片可直接设置或取消重要标记，等待后台成功后刷新显示；WebUI 删除仍保留原有确认流程。
- **更一致的界面**：统一通透玻璃质感、柔和圆角与圆形操作按钮。范围采用分段选择，重复周期直接点选，会话及所有者筛选标明选中项。优化焦点、按压与开合反馈，收敛悬浮幅度，支持减少动态效果；保留空心／实心星标、分区表单、固定底部操作栏、中英文说明和窄屏布局，输入错误自动滚入可视区域。
- **避免覆盖并发修改**：保存仅提交变化字段，单条检查目标版本，批次检查整批快照。冲突保留输入，调度失败回滚。请求超过 30 秒无响应时退出等待并提示先核对结果，不自动重复提交。
- **私聊确认更自然**：真实用户私聊中的删除（含重要提醒）和取消重要标记由 LLM 结合上下文判断是否追问，不再要求固定口令。任务归属与权限检查保留；群聊、自动事件和 WebUI 不适用这项私聊豁免。修复“确认删除”被无关的取消星标请求阻塞。
- **资源随内容更新**：前端直接资源引用带内容指纹，减少升级时新 HTML 配旧 JS／CSS 的风险，保留原样式加载顺序与本地资源分发方式。

## 升级注意事项

1. 备份 `data/plugin_data/reminder_plugin/` 和 `data/config/plugins/reminder_plugin.json`，保留现有任务和配置。更新插件后按原方式重载／重启 KiraAI，再重新打开看板；普通安装无需 Node/npm 或自行构建。
2. 本版不改变任务数据结构，无需删除插件配置。提示词来源 `auto`／`default` 使用新版默认说明；`custom` 保留自定义内容。
3. 编辑随机批次只影响保存时仍未到期的任务。范围与次数重新抽取尚未开放；自主跟进仍由意图管理流程维护，未开放表单编辑。
4. 保存冲突时先复制需要保留的输入，关闭编辑、刷新并重新打开任务。网络异常或超时不代表保存未生效，先核对结果再操作。
5. 资源指纹不清除宿主／代理缓存的旧 HTML；若仍出现旧界面或白屏，须检查实际加载的入口及资源版本。

## 兼容性与验证

- 仅修改插件；最低声明版本保持 KiraAI `>=2.24.2`。本轮完整回归环境为 KiraAI `3.0.2`，未重跑最低版本完整回归。
- 插件 Python 测试 **788 项通过**，前端与本地资源测试 **81 项通过**，覆盖批次范围、权限、并发修改、调度失败回滚及保存超时。
- 隔离浏览器验证随机批次编辑、历史记录保留、英文窄屏、固定底部按钮和键盘焦点循环。测试使用虚构数据，不操作真实提醒，不触发真实消息或脚本。
- 实际服务器升级与真实定时投递尚未验证。建议在测试会话完成普通任务编辑、随机批次基础编辑、星标切换、定时触发及保留配置升级验收。
