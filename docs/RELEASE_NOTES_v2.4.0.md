# v2.4.0｜自主模式联动与提示词更新管理

本版本让自主循环模式与工具权限同步生效，明确区分定时事件与用户消息，并支持提示词跟随默认更新或保留自定义内容，改善配置与看板说明。

> **升级前请留意：已有 `trusted_admin` 配置升级后，会自动允许 `exec` 和 `manage_background_exec`，即使原自定义工具列表没有填写它们。** 工具仍须由核心提供并通过核心执行权限检查；无需自主执行脚本时，请选择 `plan_only`、`observe` 或 `off`。

## 修复与改进

- **自主模式与工具权限联动**：`trusted_admin` 自动允许脚本执行及后台执行管理，切回保守模式收回这些能力，保留原自定义工具列表。`off` 拒绝已排队的自主请求；核心未注册或已移除的工具不会被插件重新添加。
- **定时事件来源更清晰**：推送使用 `[定时任务｜系统触发]`、`[自主跟进｜系统触发]` 等简短标记，随后保留任务内容，不追加长篇行为约束。内部事件独立处理，避免与等待中的用户消息合并；过期、伪造或混合导致身份无法确认的内部事件停止处理。
- **提示词可跟随新版默认**：提醒功能与自主检查分别支持 `auto`（自动兼容）、`default`（跟随默认）、`custom`（自定义）。自动兼容识别已知发布版本的默认文案并使用当前默认，未知或修改过的内容继续保留使用。
- **恢复默认不再牵连其他配置**：选择 `default` 并保存即可恢复默认行为，保留原自定义文本和其他配置；切回 `custom` 可继续使用原文。无需卸载插件或删除配置，默认提示词正文未扩写。
- **配置与看板更易理解**：补充各自主模式的中英文说明，明确保存后生效、核心权限限制及工具列表含义；会话输入、重复周期、空状态和确认提示改为直白表述。

## 升级注意事项

1. 升级前备份 `data/plugin_data/reminder_plugin/` 与 `data/config/plugins/reminder_plugin.json`；保留现有任务和配置，更新插件后按原部署方式重载／重启 Kira。普通安装与使用无需 npm 或重新构建前端。
2. 模式切换需保存后生效。自主总开关、允许会话、`action_policy` 与核心执行权限仍独立设置；切换模式不会终止已经开始运行的工具。`trusted_admin` 自动允许的工具不会追加显示在自定义列表中。
3. 编辑提示词后，请将对应来源选择为 `custom` 并保存。选择 `default` 时使用当前插件默认，文本框仍保留旧内容，不代表实际使用的默认文案。两项来源互相独立。
4. `custom` 下留空会关闭对应提示词。`auto` 保留旧空值语义：提醒功能提示词为空仍关闭，自主检查提示词为空仍使用默认；原自定义内容不会因升级被清空。
5. `act_with_confirm` 的工具范围仍与 `plan_only` 相同，不提供“确认后执行任意脚本”的能力。普通用户创建的定时任务继续按任务所有者进行权限校验。

## 兼容性与验证

- 不修改 KiraAI 主项目代码，最低声明版本仍为 `>=2.24.2`；本版不改变任务数据结构。
- KiraAI `3.0.2` 环境下，完整插件 Python 回归 **750 项通过**，前端与本地资源回归 **66 项通过**。
- KiraAI `2.24.2` 环境下，提示词与配置专项测试 **83 项通过**，五种模式的工具策略接口检查通过；3 项仅适用于新版提示词位置选项的测试跳过，不代表旧版本全部功能均经过完整回归。
- 测试使用临时文件和模拟事件，未在用户服务器进行真实消息发送或脚本执行验证；升级后建议在测试会话检查定时触发、模式切换及提示词来源选择。
- 已记录的浏览器前端缓存资源混用问题尚未修复；更新文件后仍应检查看板及投递问题区域，不能仅凭刷新操作认定所有资源已更新。
