## R6：损坏保留，缺字段兼容

- 自主状态缺少 `sessions`、会话默认字段或意图字段时仍按既有逻辑使用默认值；不把缺字段当成损坏。
- 已存在的 `sessions` 必须是对象、会话值必须是对象、`intents` 必须是对象列表、`random_check_times` 必须是字符串列表。违反这些已使用的结构时保留原文件并报错，不重置为空。
- 未知字段和已有有效记录保留；不验证所有业务字段，不推断字符串／null 为某种旧格式，不自动修复损坏。当前没有可靠证据支持这些错误容器的无损迁移。
- 结构规则留在自主模块。通用存储只提供可选校验回调，对自主文件在读取和提交前校验；普通提醒和投递文件不强套自主结构。本轮不宣称完成所有数据文件的深层校验。
- 工具入口明确返回自主状态不可用的错误。启动时发现自主状态不可用，跳过自主循环调度并记录原因，普通提醒仍可运行；修正文件后可重载恢复，不清空文件。
- 自主跟进已由模型确认后，若自主元数据损坏，保留损坏文件并记录同步失败，不让该异常扩散到主项目响应钩子。
- 保护范围是结构损坏；跨文件提交、写入失败及并发外部修改仍不具备强事务保证，不在本轮扩大架构。
